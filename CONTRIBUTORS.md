## Adding Non-Code Contributors

To recognize contributions that don't appear in git history, maintainers can comment on any issue or PR:

```
@all-contributors please add @username for documentation, bug
```

### Contribution Types

| Type | Key | Type | Key |
|------|-----|------|-----|
| Bug reports | `bug` | Documentation | `doc` |
| Ideas | `ideas` | Review | `review` |
| Design | `design` | Answering questions | `question` |
| Translation | `translation` | Examples | `example` |

See [emoji key](https://allcontributors.org/docs/en/emoji-key) for full list.
