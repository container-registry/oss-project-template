# Maintainers

Maintainers review and merge changes, cut releases, and handle security reports.

| Name | GitHub | Areas |

`.github/CODEOWNERS` maps paths to reviewers and is what GitHub uses to request reviews. Keep the two in sync.

## Becoming a Maintainer

Sustained, high-quality contribution over time: reviews as well as code, and enough context to say no to a
change. An existing maintainer proposes the addition in a pull request against this file; agreement of the
current maintainers carries it.

## Stepping Down

Open a pull request removing yourself. Maintainers who have been inactive for six months may be moved to
emeritus by the remaining maintainers, with no judgement implied and the door open.
